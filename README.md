# Hitch Illini

**Split the ride. Split the gas.** A carpool app for UIUC students. Drivers post trips they're already taking, and riders book a seat and split the gas cost fairly. No profit, just sharing.

- **New here?** Start with [SETUP.md](SETUP.md). It covers accounts, keys, and running the app on your phone.
- **What we're building:** [SPEC.md](SPEC.md)
- **Later ideas:** [ROADMAP.md](ROADMAP.md)

```bash
npm install
cp .env.example .env   # then fill in your keys (see SETUP.md)
npx expo start
```
